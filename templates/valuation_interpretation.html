Terminal Growth / Terminal Value / Reverse DCF / Sensitivity

Terminal value = year-5 cash flow × (1+terminal growth) / (discount rate − terminal growth). Terminal growth must be strictly below the matching discount rate.

Market value = present value of five explicit cash flows + discounted terminal value. The bounded bisection solver uses FCFF/WACC/EV or FCFE/cost-of-equity/market-cap; the two models are never mixed.
