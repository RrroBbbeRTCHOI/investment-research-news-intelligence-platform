# Moat 2 limitations

- Financial movement does not prove cause. Reconciled arithmetic identifies statement location, not management execution or an economic explanation.
- Missing disclosure remains unknown. No missing assets, inventory, tax details or evidence amounts are substituted with zero.
- The current adapter uses existing FMP annual statements with explicit metadata. It does not guess Yahoo/SEC periods or currency for missing balance fields, and does not introduce new providers. The original frozen recordings intentionally lack six balance responses; this is not a production restriction. Supplemental V1.1 tests now provide isolated synthetic annual responses for every universe ticker and verify the existing generic fetch/cache/normalize path. The shipped real-data cache still contains only AAPL balance history, and this environment has no FMP credential. Therefore the other six cannot be reported as live-data repaired. Configure FINANCIAL_API_KEY locally and restart the app; cache misses then use the existing FMP loader, subject to provider access and valid matching fields. No synthetic test rows are shipped as production cache data.
- Working-capital balance changes can reflect acquisitions, FX, reclassification and multiple operating factors. They are not automatically the cash-flow working-capital contribution, fraud signals or evidence of collection deterioration.
- Increasing CapEx is not automatically positive or negative. Arithmetic attribution cannot establish productive investment or future returns.
- Historical patterns are not forecasts. Company-specific accounting presentation, currency changes, restatements, fiscal-duration changes and overlapping expense categories can limit comparability.
- Moat 1 evidence is consumed only when passed or already fresh in the service cache. A cold Financials page can have valid arithmetic without upstream narrative references. Existing page caching may preserve that coverage until the page cache refreshes.
- No new SEC keyword system, non-core decomposition, earnings-quality score, accrual formula or financial-scoring weights are introduced. Existing N/A fields, Neutral naming and distinct price definitions remain intact.
- The original top cards may use different existing sources/period definitions from the new explicitly annual section. They have not been replaced or silently reconciled to the new data.
- Validation uses frozen synthetic MAG7 recordings and controlled numerical stress cases, not live verification that the named companies currently exhibit any particular financial behavior.
- Browser manual visual verification remains incomplete: the sandbox blocked a local listening port and the request to run the offline server with elevated permission was rejected. Automated Flask responses, sections, preserved cards and cache behavior were checked for all seven. No browser-policy workaround was used.
